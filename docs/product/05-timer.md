# עמוד: טיימר מנוחה (Rest Timer)

**קובץ מקור:** `public/index.html` — `#sec-timer` (שורות ~948–995), לוגיקת JS תחת "TIMER" (שורות ~3813–4080).

## מטרת העמוד

טיימר ספירה לאחור בין סטים באימון כוח. עמוד עצמאי בניווט התחתון (לא קופץ כמודל מעל טופס האימון) — כדי לאפשר שימוש בו-זמנית בטיימר תוך מעבר חופשי בין עמודים.

## שני מצבי תצוגה (View States)

### 1. מצב הגדרה (`tv2SettingView`) — ברירת מחדל
- שני "גלגלי גלילה" אנכיים אינסופיים (Custom Scroll Wheel Picker) — אחד לדקות, אחד לשניות, מופרדים ב-":". זהו רכיב UI מותאם אישית (לא `<input type=number>` רגיל) הבנוי ידנית עם `pointerdown/pointermove` ופיזיקת "מומנטום" (חיכוך, האצה, snap לערך שלם).
  - כל גלגל טוען טווח ערכים 00–59 ומשוכפל פי 3 (0–179 שורות פנימיות) כדי לייצר תחושת גלילה אינסופית ללא "קצה" — עם "עטיפה" (`_wrap`) שמזיזה את המיקום בחזרה למרכז כשמתקרבים לקצוות השכפול.
  - נתמכת גם גלילת עכבר (`wheel` event) לצורך שימוש בדסקטופ/QA.
  - הערך האחרון שהוגדר נשמר ל-`localStorage` (`timerLastSecs`) ונטען כברירת מחדל בפעם הבאה.
- כפתור "התחל" עגול גדול (▶) במרכז התחתון.

### 2. מצב ריצה (`tv2RunningView`)
- טבעת התקדמות מעגלית (SVG) שמתמלאת בהדרגה ככל שהזמן חולף (`stroke-dashoffset`, אנימציה חלקה של 0.9 שניות), עם הזמן הנותר במרכז הטבעת (`MM:SS`) והזמן הכולל מתחתיו.
- כשהטיימר מסתיים, הטבעת עוברת לצבע ירוק (`.done`).
- שני כפתורי בקרה: **עצור** (מרובע אדום, `tv2Stop` — מאפס לגמרי וחוזר למצב הגדרה) ו-**השהה/המשך** (עיגול סגול גדול, `tv2TogglePause` — מחליף בין אייקון pause לאייקון play).

## אינדיקציה גלובלית בניווט התחתון

- כשיש טיימר פעיל, **אייקון ה"טיימר" בניווט התחתון עצמו משתנה לזמן הנותר** (`MM:SS` בטקסט, במקום שם הטאב "טיימר") — כך שהמשתמש רואה את הספירה לאחור גם כשהוא עבר לעמוד אחר (למשל חזרה לטופס האימון בין סטים). בסיום, האייקון הופך זמנית לסימן ✓ לפני שחוזר לאייקון השעון הרגיל.
- מעבר לעמוד הטיימר עצמו (`showSection('timer')`) בודק אם טיימר כבר רץ ומציג את התצוגה המתאימה (running/setting) — כך שהמשתמש לא "מפספס" מצב קיים.

## סיום הטיימר

בהגעה ל-0:
1. רטט מכשיר (`navigator.vibrate`, דפוס [200,100,200,100,400]) אם נתמך.
2. צליל ביפ משולש (Web Audio API, גל סינוס 880Hz) — **מותנה בהגדרת המשתמש** (ראו `08-settings.md` → "צליל בסוף טיימר").
3. הודעת Toast "⏰ זמן המנוחה הסתיים!".
4. אחרי 1.5 שניות השהיה (משאיר את מצב ה"הושלם" הירוק גלוי לרגע), הטיימר מתאפס אוטומטית וחוזר למצב הגדרה עם הערכים האחרונים.

## הרשאת התראות (Notifications)

- בהתחלת טיימר, אם הדפדפן תומך ב-Notifications API והמשתמש עדיין לא ענה לבקשת הרשאה — מבוקשת הרשאה (`Notification.requestPermission()`). **הערה:** בקוד הנוכחי לא נמצא שימוש בפועל בשליחת התראת Push כשהטיימר מסתיים והאפליקציה ברקע — הבקשה קיימת אך אינה מנוצלת במלואה (מפתחות תרגום `timer.done_notif` ו-`timer.allow_notif` קיימים ב-`translations.js` אך לא מקושרים כרגע לקוד פעיל שנמצא).

## מקרי קצה

- לחיצה על "התחל" עם 00:00 בשני הגלגלים — לא קורה כלום (הפונקציה בודקת `total <= 0` ויוצאת בלי להתחיל).
- החלפת שפה (עברית/אנגלית) בזמן שהטיימר במסך הגדרה מרעננת את תוויות "דקות"/"שניות" בלי לאפס את הערכים שנבחרו.
