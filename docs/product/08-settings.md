# עמוד: הגדרות (Settings)

**קובץ מקור:** `public/index.html` — `#sec-settings` (שורות ~1146–1237), לוגיקת JS: "SETTINGS UI", "RUNNING SETTINGS" (חלקים), "THEME" (שורות ~1362–1418).

## מטרת העמוד ונגישות

עמוד ריכוזי לכל ההגדרות וההעדפות. **אינו חלק מהניווט התחתון** — נגיש אך ורק דרך אייקון גלגל שיניים (⚙) בפינת הסרגל העליון בכל אחד מעמודי התוכן (כוח, טיימר, מדידות/אירובי, היסטוריה). כפתור "← חזרה" קורא ל-`history.back()` — חלק ממנגנון ניווט מאוחד המבוסס על מחסנית history אמיתית (לא משתנה יחיד), כך שרצף ניווט מרובה-שלבים (למשל טיימר → הגדרות → עריכת תוכנית → הגדרות → חזרה) מחזיר תמיד לעמוד הנכון, ללא קשר לכמה מסכי-ביניים נפתחו בדרך. פירוט ב-`docs/superpowers/specs/2026-08-30-unified-navigation-history-design.md`.

## מבנה: קבוצות הגדרות

### קבוצה 1: עריכה
שני פריטי ניווט (לא הגדרות בעצמן, אלא קישורים למסכי עריכה מפורטים במסמכים נפרדים):
- **"לעריכת תוכנית אימוני כוח"** → `03-workout-template-editor.md`.
- **"עריכת סוגי מדידות"** → פרק "עורך סוגי מדידה" ב-`06-measurements.md`.

### קבוצה 2: פרופיל
- **שם תצוגה** (`displayNameInput`) — טקסט חופשי המוצג בכל סרגל עליון בכל עמודי האפליקציה (במקום כתובת המייל). נשמר בשתי שכבות: `localStorage` (מיידי, ממותג לפי `uid`) ו-Firestore (`users/{uid}/config/profile`, `merge: true`) — כך שהשם מסתנכרן גם למכשירים אחרים של אותו משתמש. אם משאירים ריק ושומרים, השם נמחק וחוזרים להצגת כתובת המייל.

### קבוצה 3: מראה
- **ערכת נושא** — שלושה כפתורים: בהיר / כהה / אוטומטי. "אוטומטי" עוקב אחרי הגדרת מערכת ההפעלה (`prefers-color-scheme`) בזמן אמת. הבחירה נשמרת רק ב-`localStorage` (**לא מסונכרן ל-Firestore** — הגדרה זו היא per-device, לא per-user).
- **שפה** — כפתורים דינמיים הנבנים מתוך `LANGUAGES` ב-`translations.js` (כרגע עברית/אנגלית בלבד). שינוי שפה מיידי, ללא רענון דף, כולל היפוך כיוון הדף (RTL↔LTR). מפורט ב-`09-i18n-and-theming.md`. נשמר רק ב-`localStorage`.
- **"הצג עמוד אירובי" (Feature Gate Toggle)** — **מוצג רק** אם כתובת המייל של המשתמש המחובר נמצאת ברשימת ההיתר הקשיחה בקוד (`eitan357@gmail.com`, `test@gmail.com`). לכל שאר המשתמשים השורה כולה מוסתרת (`display:none`), לא רק מנוטרלת — כלומר אין להם שום רמז לקיום הפיצ'ר. מפורט מלא ב-`07-running-cardio.md`.

### קבוצה 4: טיימר
- **"צליל בסוף טיימר"** (מתג) — קובע האם ישמע ביפ כשהטיימר מגיע ל-0. נשמר רק ב-`localStorage` (`timerSound`). ברירת מחדל: מופעל.

### פעולה: יציאה
- כפתור "יציאה" (`handleLogout`) בתחתית העמוד, בעיצוב מובחן (מסגרת אדומה) כדי לסמן פעולה משמעותית — אך **ללא דיאלוג אישור** (התנתקות מיידית בלחיצה אחת). מפורט מעברי המצב ב-`01-auth-onboarding.md`.

## חלוקת אחסון: מה נשמר איפה (חשוב להבנת המוצר)

| הגדרה | `localStorage` (מכשיר) | Firestore (חשבון) |
|---|---|---|
| שם תצוגה | ✓ (ממותג לפי uid) | ✓ |
| ערכת נושא | ✓ | ✗ |
| שפה | ✓ | ✗ |
| הפעלת עמוד אירובי | ✓ (קאש) | ✓ (מקור אמת) |
| צליל טיימר | ✓ | ✗ |

**המשמעות המוצרית:** משתמש שמתחבר ממכשיר חדש יראה שוב את ערכת הנושא/שפה/צליל בברירת המחדל של המכשיר (לא מה שהגדיר במכשיר אחר), אך שם התצוגה שלו ומצב הרשאת האירובי כן יעברו אוטומטית. זו החלטת מוצר סמויה שכדאי להיות מודעים לה — לא מתועד היום למשתמש בממשק.

## אתחול המסך (`initSettingsUI`)

בכל כניסה לעמוד ההגדרות: מסונכרנים מחדש כפתורי ערכת הנושא הפעילה, מצב מתג צליל הטיימר, בורר השפה, ערך שם התצוגה מה-`localStorage`, ונבדקת מחדש הרשאת האירובי מול כתובת המייל הנוכחית (כדי שהמצב תמיד עדכני, גם אם השתנה מאז הטעינה הראשונית).
